# Urban Routes – Test Design Project

This project focuses on QA test design techniques applied to form validation in the Urban Routes application.

The project demonstrates structured manual testing practices, equivalence partitioning, boundary value analysis, and detailed test case creation used to validate input fields and application behavior.

---

# Project Objectives

The main objective of this project was to design effective test scenarios to validate form fields and ensure reliable user input handling.

The project includes:

- Equivalence Partitioning
- Boundary Value Analysis
- Manual Test Case Design
- Input Validation Testing
- Functional Testing Documentation
- Structured QA Documentation

# Test Design Techniques Applied

## Equivalence Partitioning

Validation classes were created to identify:

- Valid inputs
- Invalid inputs
- Special characters
- Empty fields
- Character limits
- Numeric validation
- Latin and non-latin characters

---

## Boundary Value Analysis

Boundary testing was applied to validate:

- Minimum accepted characters
- Maximum accepted characters
- Invalid limits
- Edge-case scenarios

Examples:

- 1 character
- 2 characters
- 13 characters
- 14 characters
- 15+ characters
